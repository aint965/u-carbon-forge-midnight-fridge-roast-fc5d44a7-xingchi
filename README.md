# Midnight Fridge Roast

One line of text roasting a smart fridge that refuses to open after midnight — the fridge locks itself at midnight like the leftovers filed a restraining order against its owner.

Entry for the [Midnight Fridge Roast bounty](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) on make.fun. The entry program (`main.ts`) writes the roast to `/output/entry.txt`.
